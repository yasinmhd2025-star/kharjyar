# خرج‌یار (Kharjyar)

اپلیکیشن مدیریت درآمد و هزینه برای اندروید با Kotlin و Jetpack Compose.

## امکانات
- ثبت درآمد و هزینه با دسته‌بندی
- داشبورد: موجودی کل، جمع درآمد و هزینه، نمودار دایره‌ای هزینه‌ها
- لیست تراکنش‌ها با فیلتر (همه / درآمد / هزینه) و حذف
- منوی کشویی (Navigation Drawer)
- حالت تاریک و انتخاب واحد پول (تومان / ریال)
- ذخیره دائمی روی گوشی (SharedPreferences)
- رابط کاملاً راست‌چین (فارسی)

## اجرا
1. پوشه پروژه را در Android Studio (نسخه Koala یا جدیدتر) باز کنید.
2. صبر کنید Gradle Sync کامل شود (اینترنت لازم است).
3. یک امولاتور یا گوشی وصل کنید و دکمه Run را بزنید.

نیازمندی: JDK 17 (همراه Android Studio هست)، minSdk 24.
